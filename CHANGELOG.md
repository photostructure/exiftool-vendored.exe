# Changelog

**The `MAJOR.MINOR` version** is the vendored ExifTool version: ExifTool 13.61
ships as 13.61.0.

**The `PATCH` version** counts releases of that ExifTool version, so a fix to
this package alone ships as 13.61.1.

- 📦 ExifTool updates and packaging changes
- 🐞 Bug fixes

`npm run update:exiftool` writes the note for a new ExifTool version, which
links to that version's entry in the
[ExifTool version history](https://exiftool.org/history.html).

Releases through 13.60.0 are described on the
[GitHub Releases](https://github.com/photostructure/exiftool-vendored.exe/releases)
page.
